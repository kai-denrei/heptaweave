# Ink Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A locally hosted `ink.html` that plays heptaweave's rules with the prompt glyph painted into a dissolving WebGL fluid, plus a test panel with shareable presets.

**Architecture:** Extract a Renderer contract from `main.js` so rules and rendering are separate; move the SVG pipeline into `render/paper/` unchanged; add `render/ink/` (fluid engine, glyph painter, ink renderer); add `params.js` + `test/` for tunables and presets. Spec: `docs/superpowers/specs/2026-09-03-ink-theme-design.md`.

**Tech Stack:** Vanilla ES modules, WebGL1 (half-float FBOs), SVG. No bundler. Node for pure smoke tests, headless Chrome for screenshots.

## Global Constraints

- No Latin characters or Arabic numerals on the play surface (test panel excepted — dev surface).
- Renderer never reads rules; `main.js` never touches canvas/SVG.
- Fluid engine is our own implementation (no code lifted from the unlicensed demo).
- Paper theme must be visually unchanged after the refactor (`index.html` behaviour identical).
- Keep `scripts/smoke-pure.mjs` passing (`node scripts/smoke-pure.mjs`).
